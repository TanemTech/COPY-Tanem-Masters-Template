# TANEM — Shablon For Only Masters

Единый production-шаблон TANEM для индивидуальных мастеров. Не используется для салонов.

## Принцип

Новый сайт собирается данными, а не ручной переделкой верстки:

```
данные мастера + фото
        ↓
     site-data.mjs
        ↓
универсальный Master Engine
        ↓
готовый mobile + desktop сайт
```

Основные HTML/React/CSS-файлы при создании обычного клиентского сайта не редактируются.

## Что поддерживает Master Engine v1

- Hair и Nails как первые два утвержденных типа мастеров.
- Hair: утвержденная мобильная декорация ножницы/расческа.
- Nails: утвержденная мобильная анимация палитры.
- На desktop эти мобильные декоративные объекты скрыты.
- Есть логотип / нет логотипа.
- Известен опыт / опыт неизвестен без выдумывания цифр.
- Три структуры услуг: варианты, простая услуга, услуга с описанием.
- 1 категория / ровно 2 категории / 3+ категорий.
- Прямая запись / ссылка конкретной услуги / запись через контакты.
- Телефон без мессенджера — допустимый и полноценный сценарий.
- Россия: RU + EN.
- Другая страна: местный язык + RU + EN.
- Автовыбор языка браузера и сохранение выбора посетителя.
- Instagram запрещен валидатором во всех публикуемых ссылках.
- Галерея, lightbox, отзывы, блок мастера, визит, анимации и scroll-lock.

## Главные файлы

- `app/master-template.tsx` — единый движок.
- `app/template.css` — единый канонический CSS.
- `public/template-runtime.js` — общий browser runtime.
- `site-data.mjs` — пустой конфиг конкретного мастера.
- `template-rules.mjs` — чистые правила выбора сценариев.
- `RULES.md` — утвержденная бизнес-логика «если / если нет».
- `SOURCES.md` — точные проверенные источники механики и commit SHA.
- `FACTORY.md` — протокол производства партий сайтов.
- `scripts/validate-site.mjs` — блокирующая проверка данных.
- `tests/*.test.mjs` — unit-тесты правил.
- `scripts/qa-scenario-builds.mjs` — реальные production-сборки разных сценариев.

## Безопасность изменений

Pull request выполняет все проверки, но не публикует GitHub Pages. Публикация выполняется только из `main` после успешных проверок.

Одобренная Hair-декорация при сборке копируется из зафиксированного commit исходного Hair-шаблона. Это гарантирует точный исходный файл без приблизительного воссоздания.

## Для создания сайтов

Не копируйте клиентские данные из эталонных сайтов. Источники в `SOURCES.md` используются только для утвержденной механики.

Для массовой работы следуйте `FACTORY.md`.
